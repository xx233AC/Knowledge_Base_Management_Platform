# 暗色动态设计预览

直接用浏览器打开同目录的 `05-motion-preview.html`。Vue 3.5.44 运行文件已内嵌，页面无需 CDN、安装依赖或后端。

## 已实现的场景

- 登录页：左右共用一层炭黑背景与像素点阵，右侧表单无独立底板；点阵响应指针，知识书页与知识节点图形切换；点击图形可重播像素转场。
- 数据看板：数字、折线和柱条过渡；响应时间保留小数。指标、趋势和排行由同一批 42 轮演示日志计算。
- 知识单元：列表入场、筛选、分页、演示新增、详情面板；新增仅在当前页面内存中保留。
- 导入中心：文件选择/拖放、逐文件格式提示、五阶段流程播放、停止和重新播放。
- AI 对话：新消息入场、模拟流式回复、停止、会话切换、引用与权限提示。

顶部工具栏用于切换场景、减少动态和重播。系统偏好为减少动态时默认静态显示。

## 运行边界

这是设计交互原型，完整业务前端尚未搭建。所有账户、文件处理和问答是本地演示，不连接 MinerU、模型或后端；不会发送账号信息或上传文件。

设计以 React Bits / Vue Bits 的交互思路为参考，针对本项目编写 Vue、Canvas 和 CSS 实现。未复制 React 组件，未引入 React 运行时。原型保留内嵌 Vue 的许可证说明。
