| 响应式 | 1440/768/390，收起侧栏、移动知识卡片/批量选择 | 密集组织表格在容器内横向滚动，不撑宽页面 |

## 核验记录

- `npm test`：33 条通过，覆盖权限 OR/默认拒绝、无管理员旁路、统计汇总、账号停用/过期、CRUD/版本/持久化、关联保护、FAQ 缓存/撤权、SSE 分片/完成/错误/取消和 API 适配器。
- `npm run build`：类型检查与生产构建通过；另外构建了 api 模式用于浏览器验证。
- 浏览器主流程：63 项检查通过，包含三角色入口、知识创建编辑刷新、FAQ 发布、缺口取消建档、格式校验与导入、问答、403、个人中心和 13 个页面的三尺寸溢出检查。
- 独立问题回归：10 项通过，包含打开的旧版本/FAQ 弹窗撤权清除、延迟轮询不可覆盖取消状态、刷新保持取消，以及独立用户维护权限、导入结果先授权后进入详情。
- 生产构建：10 项通过，包含 demo 登录、移动批选/确认/ESC、Markdown 危险内容不执行、api 隐藏演示入口、后端失败不回退、无外部 CDN、无运行异常。
- 登录页设计检查：0 FAIL、2 WARN。保留已确认的 36px 品牌主张；11–12px 用于辅助标注与演示说明，表单与正文保持较大字号。已查看桌面/平板/手机实际截图。
- 官方 npm registry 的生产依赖审计：0 vulnerabilities。此结果不替代后续后端安全测试。
- 独立代码审阅发现的缓存引用、撤权弹窗、取消竞态、来源发布状态、目录读权与负责人关联问题已修复，增加回归覆盖，定点复核无剩余阻断项。
