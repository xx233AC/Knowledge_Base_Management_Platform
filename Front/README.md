# 知识库管理平台 · Front

独立 Vue 3 + TypeScript 前端工程，沿用已确认的暗色、轻像素风格。FastAPI 后端位于同级 `Back`，按 `docs/API-CONTRACT.md` 与现有请求适配器提供接口。

## 启动

需要 Node.js 22.12+（已在 Node 24.16 上验证）。在本目录执行：

```powershell
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 。此地址为正式前端开发服务；早期 `64760/05-motion-preview.html` 只是设计原型。

## 演示身份

默认使用本地演示模式，以下账号密码均为 `Demo@123`。

| 用户名 | 角色 | 登录后首页 |
|---|---|---|
| admin | 系统管理员 | 数据看板 |
| knowledge | 知识管理员 | 知识工作台 |
| member | 普通用户 | AI 对话 |

登录页可选择身份自动填写，然后点击登录。角色权限可配置；上表是初始分工。系统管理员没有知识内容的隐式通行权。

演示数据存于当前站点的 localStorage，登录会话存于 sessionStorage，默认有效 8 小时。刷新保留业务变更；关闭标签页后需要重新登录。个人中心可确认后重置演示数据。所有人名、知识、日志都是虚构样本；导入只保存文件元信息，不上传或解析真实文档；AI 是本地模拟，不调用模型或 MinerU。

## 已实现模块

- 登录、个人中心、动态菜单、路由与按钮权限、三角色不同首页。
- 用户增改、角色关联、启停用、密码重置；角色权限树；部门树、负责人、成员与关联删除保护。
- 知识搜索、分类/状态筛选、分页、详情、Markdown 编辑、标签、附件关联、版本记录与批量删除。
- 全局/部门/角色/个人混合授权，任一匹配放行，空授权默认拒绝。
- 单文件、多文件、目录、拖放、大小/格式校验、有限并发、任务进度、取消、失败重试与已提交任务刷新恢复。
- 多轮对话、历史会话、模拟/API SSE 流、停止、清洗后的 Markdown、引用、无授权与无命中提示。
- 看板指标、问题榜、知识榜、按日/周趋势、Token 趋势及响应耗时分布。
- FAQ 推荐审核、编辑发布/驳回、已发布库、下线与缓存状态；知识缺口详情、忽略/重开、建档关联。

已导入的知识默认无授权，先在知识列表点击“授权”，授予当前人员或角色后，再查看、编辑和发布。演示附件仅展示信息；真实原文件存储与下载需要后端提供文件服务，目前没有假下载按钮。

## 切换到接口模式

复制 `.env.example` 为 `.env.local`，修改后重启开发服务：

```dotenv
VITE_DATA_MODE=api
VITE_API_BASE_URL=/api
```

开发时 `/api` 代理到 `http://127.0.0.1:8000`，可在 `vite.config.ts` 修改。模式由构建环境决定，切换后需重启或重新构建。API 模式不会回退到演示数据；没有后端时会明确报错。不要把模型或 MinerU 密钥写入任何 `VITE_` 变量。

前端已经实现请求适配器和流式协议；尚未与真实服务联调。`docs/API-CONTRACT.md` 列出当前实际请求、约定的补充接口、响应模型和待后端实现的行为。

## 检查与构建

```powershell
npm test
npm run typecheck
npm run build
npm run preview
```

`dist/` 为静态构建结果。资源和字体均本地打包，无 CDN 依赖。`npm run preview` 在 4173 提供构建预览。

## 当前运行方式

按用户要求，旧的本地 Dockerfile、Compose、Nginx 文件及 Deploy 旧部署目录中的文件已备份后移除。前端继续使用 `npm run dev`；后端通过 PyCharm/本机 Python 运行，基础设施通过 SSH 隧道访问服务器。参见 `../Back/README.md`。
